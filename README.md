# GRC105 Incident Response Planning Assignment

Course: GRC105 Incident Management and Business Continuity, ICDFA
Scenario: Northbridge Skills Institute (fictional), suspected ransomware incident

## Contents
* Task 1: incident timeline, severity assessment and investigation priorities
* Task 2: response plan, CSIRT, RACI matrix and readiness checklist
* Task 3: response playbook, evidence register and recovery acceptance criteria
* Task 4: communication matrix, executive briefing, learner notice and notification assessment
* Task 5: tabletop exercise, decision log and improvement plan
* Task 6: healthcare ransomware case study analysis

The full assignment is provided as a Word document and a PDF.

## Notes
All organisations, people, contact details and data are fictional.
